# Thí nghiệm và kết quả đo

Mỗi thí nghiệm dùng mã `EXP-XX` và phải lưu:

- mục tiêu/kịch bản chất lượng được kiểm chứng;
- commit, cấu hình môi trường và dữ liệu;
- workload và điều kiện chạy;
- bất biến cần kiểm tra;
- script có thể chạy lại;
- kết quả thô, phân tích và hạn chế.

Chỉ tạo bản đối chứng khi câu hỏi đánh giá thực sự cần so sánh hai phương án.
