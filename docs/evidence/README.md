# Bằng chứng

- `external-survey/`: ảnh, URL, ngày quan sát và bảng khảo sát các luồng công khai.
- `incident-diagnosis/`: quy trình dò lỗi thủ công, dữ liệu đầu vào, điểm nghẽn và thời gian ghi nhận.

Không commit log chứa token, cookie, email, số điện thoại, dữ liệu thanh toán hoặc dữ liệu cá nhân chưa khử nhạy cảm.
