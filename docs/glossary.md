# Từ điển miền

**Trạng thái:** Khung chờ hoàn thiện ở B2 — chưa dùng làm căn cứ chốt ranh giới service.

| Thuật ngữ | Định nghĩa thống nhất | Phân biệt với | Context dự kiến | Trạng thái |
|---|---|---|---|---|
| Kiến trúc đích | Thiết kế được lập luận từ vấn đề, nghiệp vụ, bất biến và quyền sở hữu dữ liệu của đồ án | Cấu trúc package hiện tại | Toàn hệ thống | Đã chốt |
| *(Bổ sung ở B2)* |  |  |  | Nháp |

Khi làm B2, nhóm phải định nghĩa tối thiểu các cặp dễ nhầm như giữ chỗ/đặt hàng, vé/loại vé/tồn kho vé, thanh toán/đối soát/hoàn tiền và sự kiện nghiệp vụ/sự kiện miền.
