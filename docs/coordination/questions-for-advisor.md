# Nội dung cần xác nhận với giảng viên hướng dẫn

- **Trạng thái:** Đã soạn, chưa gửi.
- **Người gửi dự kiến:** Lê Văn Minh hoặc đại diện nhóm.

## Tin nhắn ngắn đề xuất

> Thưa cô, nhóm em đang bắt đầu xây dựng khung tài liệu cho đồ án tốt nghiệp “Hệ thống đặt vé sự kiện trực tuyến”. Để tránh dùng nhầm format của môn Thực tập cơ sở, cô cho nhóm em xin đề cương/cấu trúc báo cáo ĐATN và file mẫu trình bày hiện hành của Khoa CNTT 1 được không ạ? Nhóm em cũng muốn xác nhận các sản phẩm phân tích–thiết kế cô mong đợi, đặc biệt là thiết kế tương tác, phương pháp phát triển phần mềm và các sơ đồ UML bắt buộc. Trong lúc chờ mẫu, nhóm em vẫn tiếp tục khảo sát, phân tích nghiệp vụ và ghi lại quyết định kiến trúc, chưa khóa số chương. Em cảm ơn cô.

## Khi nhận phản hồi cần ghi lại

| Nội dung | Phản hồi của cô | Ngày | Tài liệu bị ảnh hưởng |
|---|---|---|---|
| Số chương/cấu trúc bắt buộc |  |  | `report/report-outline.md` |
| File mẫu font, lề, heading, đánh số |  |  | Tầng C và file báo cáo |
| Yêu cầu về thiết kế tương tác |  |  | Giai đoạn 3–4 |
| Yêu cầu về phương pháp phát triển phần mềm |  |  | Khung báo cáo và nhật ký thực hiện |
| Danh sách/độ sâu sơ đồ UML |  |  | Tầng B/C, kế hoạch sơ đồ |
| Yêu cầu chứng minh kiến trúc khớp mã nguồn |  |  | B5.5, kiểm tra cuối Giai đoạn 7 |

Không tự suy ra câu trả lời từ tài liệu Thực tập cơ sở; các tài liệu đó chỉ là nguồn tham khảo phong cách.
